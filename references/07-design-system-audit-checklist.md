# 07 设计系统自查走查清单 (Design System Audit Checklist)

无论是人工设计师验收，还是 AI Agent 完成代码生成后的自我走查，必须逐条核对以下 15 项硬门禁。全部通过后方可交付。

---

## 走查清单概览表

| 编号 | 检查维度 | 验收标准 | 检查方法 / 关键判据 |
| :---: | :--- | :--- | :--- |
| **01** | **阴影裁切 (Shadow Clip)** | 容器内所有阴影完整展开，无截断现象 | 检查带 `shadow` 的元素祖先是否带有 `overflow: hidden/auto`；外周余量 $\ge$ 模糊半径+偏移 |
| **02** | **同心圆角 (Concentric Radius)** | 内外圆角平行自然，无挤角缺陷 | 核算：外层圆角 = 内部元素圆角 + 容器内边距 |
| **03** | **0.5px 微边框** | 分割线与卡片边框轻盈细腻，拒绝粗黑 | 采用半透明 RGBA 色值（如 `rgba(226,232,240,0.7)`）或物理 0.5px 缩放 |
| **04** | **光学视觉重心** | 图标+文字按钮、弹窗位置重心微调 | 图标不机械死板居中；弹窗垂直位置在视口黄金分割位（38.2%）或偏上 |
| **05** | **去占位废话** | 卡片与表单无占位副标题，说明文字零赘余 | 标题直抒胸臆，输入框占位符仅留必要格式提示，靠布局排版传递意图 |
| **06** | **主按钮唯一性** | 一个独立操作区最多只能有 1 个 Primary 按钮 | 扫描页头、表格工具栏、弹窗底部，确保无两个实心深色按钮并列 |
| **07** | **审批中立性** | 审批或严肃责任二选一区域无主操作倾斜 | “通过”与“驳回”均采用次级按钮样式，不带偏向性配色诱导 |
| **08** | **Badge 80% 浅底深字** | 状态标签采用浅底搭配深色文字 | 严禁彩虹配色，严格遵循六大业务语义映射表（绿/橙/红/蓝/青/灰） |
| **09** | **单选/开关/下拉选型** | 2-4项单选平铺，立即生效用开关，>5项用下拉 | 检查选项数量是否符合否定判据，无滥用 Select 的现象 |
| **10** | **弹窗防手滑丢失** | 表单录入弹窗必须禁用点击遮罩关闭 | `maskClosable={false}`，并在表单有脏数据时拦截意外退出 |
| **11** | **高危破坏性操作阻力** | 涉及删除、扣款的操作具备充分心理阻力 | 标题中立交代对象，描述写清后果与不可逆性，按钮文案动宾明确（如“彻底删除”） |
| **12** | **表格三向对齐** | 文本居左、数值与时间居右、复选框居中 | 检查金额与计数列是否右对齐，确保个十百千位数精准竖直对齐 |
| **13** | **横向滚动容器隔离** | 超宽表格仅在自身容器内滚动，主页面无横滚 | 页面外层 `clientWidth === scrollWidth`，固定列有明确宽度与视觉分割线 |
| **14** | **全状态五态覆盖** | 任何数据区域具备理想、空、加载、错误、受限五态 | 空状态必须有为什么为空的解释 + 一键创建或清除筛选的行动出口 |
| **15** | **禁止手搓轮子** | 弹窗、下拉、折叠面板等复用成熟组件库 | 统一基于成熟库（如 shadcn/ui、antd）封装，严禁用原生 div 从零拼凑 |
| **16** | **等宽数字防抖 (Tabular Numerals)** | 统计看板、指标卡、表格数值全量等宽 | 检查是否声明 `font-variant-numeric: tabular-nums`，彻底消除动态跳动乱抖 |
| **17** | **文字防孤字成行 (Text Wrap Balance)** | 关键标题与引导文本行距平衡 | 检查标题是否启用 `text-wrap: balance`，杜绝最后一个单字孤立掉行 |
| **18** | **出海短词膨胀保护 (Text Expansion)** | 按钮与表单操作区无固定写死像素宽度 | 按钮容器使用 `flex-1` 弹性填充或 `min-w + px-4`，多语言下不撑爆卡片 |
| **19** | **出海多语言音标与 RTL 规范** | 泰语/越南语等变音符号不削顶，阿语逻辑属性 | 多语言行高 $\ge 1.5$ 且无滥用 `overflow: hidden`；RTL 下进度条与数字强制保持 LTR |
| **20** | **查询分层与防卡死 (Query Architecture)** | 基础筛选平铺 $\le 4$ 个，大数据量/慢查询带查询按钮 | 严禁无节制平铺 10+ 筛选；大数据集禁止每改一字就触发全局卡死转圈 |
| **21** | **时间区间防呆与基准线** | 预设 Pills 外露，跨度有最大防呆天数限制 | 今天/近7天快捷胶囊外露，双日历设置最大跨度限制，未来日期禁用 |
| **22** | **去 AI 味：页面默认平 (Zero Fluff & Flat)** | 常规卡片默认纯平用 0.5px 微边框切分，阴影只给浮层 | 检查卡片无滥用 `shadow-lg` 或多重发光，全页单一强调色，无意义 eyebrow 全清 |
