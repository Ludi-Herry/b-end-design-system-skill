# 02 基础原子组件规范 (Primitive Components)

原子组件是界面构成的最基本积木。必须确保组件语义唯一、视觉层级自洽、业务状态映射稳定，杜绝同类组件的混乱拼凑。

---

## 一、按钮组件：层级与决策法则 (Button Hierarchy)

按钮承载界面的行动意图。一个操作区内按钮样式的混乱，是破坏用户心智模型的罪魁祸首。

### 1. 五档视觉层级

| 变体 (Variant) | 视觉特征 | 适用场景 | 关键约束 |
| --- | --- | --- | --- |
| `primary` (主按钮) | 实心高饱和品牌色填充 | 整个操作区**最高频、最推荐**的核心主任务 | **一个操作区内严禁出现 2 个及以上 primary 按钮** |
| `secondary` / `outline` (次级按钮) | 浅底或 0.5px 微边框描边 | 辅助操作、取消、重置、导出等常规动作 | 并列次操作统一使用该变体 |
| `ghost` / `text` (文本按钮) | 无背景无边框，仅文字+悬浮微底色 | 表格操作列内的每行动作、次级折叠触发 | 极度节省横向空间，不打扰表格数据扫读 |
| `danger` (危险按钮) | 醒目红色（填充或描边） | 删除、停用、清空、注销、强制中断等高危操作 | **禁止用 primary 加红色样式硬改**；高危操作必须配二次确认 |
| `link` (链接按钮) | 纯文字带外链跳跃语义 | 跨页面跳转、查看第三方文档 | 如果是当前页操作，严禁用 link 假扮按钮 |

### 2. 主操作判定五步法 (Primary Action Decision)

在一个具体的操作区（如页头、表格工具栏、弹窗底部）：
1. **统计频次**：列出所有按钮，找出用户在此处**最高频、最通用**的动作，只有它配叫主操作。
2. **低频降权**：低频或影响极大的动作（如仅管理员每月用一次的“批量重置”），即便重要也应降为次级按钮或折叠进“更多”菜单。
3. **审批与责任决策中立原则**：在需要用户客观严肃决策的场景（如“审批通过”与“审批驳回”、“同意责任条款”与“拒绝”），**该区域不设主按钮**！两方均采用 `secondary` 次级样式，保持界面绝对中立，严禁用视觉色差诱导用户。
4. **状态联动切换**：同一对象在不同生命周期下最高频动作发生变化时，主操作可以动态切换，但**同一时刻仍只能保留一个主操作**。
5. **折叠菜单保底**：“更多操作”下拉菜单里如果最后只剩下 1–2 项，应直接平铺展示，禁止为了折叠而折叠。

## 二、Badge 徽标与业务状态：防滥用与黄金法则 (Badge & Status)

> **B 端最容易被滥用的组件就是 Badge。** 许多开发者或 AI 喜欢为了“让页面色彩丰富好看”，将不同颜色轮着用，彻底毁掉业务状态的严肃性。

### 1. 业务语义与 Variant 强绑定映射表

| 业务语义 | Variant | 背景色 | 文字色 | 示例场景 |
| --- | --- | --- | --- | --- |
| **正常 / 完成 / 健康** | `success` | `#f0fdf4` | `#16a34a` | 运行中、已上线、同步成功、支付完成 |
| **待办 / 预警 / 审批中** | `warning` | `#fff7ed` | `#ea580c` | 待审核、库存紧张、证书即将到期 |
| **危险 / 错误 / 阻断** | `danger` | `#fef2f2` | `#dc2626` | 离线、同步失败、违规封禁、欠费停服 |
| **中性 / 常规信息** | `info` | `#f0f9ff` | `#0284c7` | 草稿、队列中、普通备注 |
| **进行中 / 活跃** | `processing` | `#eff6ff` | `#2563eb` | 正在构建、导入中（通常带微动画点） |
| **已停用 / 次级归档** | `secondary` | `#f1f5f9` | `#475569` | 已下线、已归档、历史记录 |

### 2. “浅底深字” 80% 黄金法则 (Soft Background Rule)
- **浅底深字是 80% 业务场景的首选**：纯白字配深红/深绿实心底色视觉冲击过大，多行表格中会导致严重的视觉跳跃和眩晕。实心底色仅限极小未读红点（Dot）或灾难级 Alert。
- **业务文案不能省**：严禁只给颜色不给文字！颜色只是视觉辅助，Badge 内部必须清晰写明具体业务状态文案（如“审核中”、“已驳回”）。
- **同一个含义全项目只用一个 Variant**：禁止在页面 A 叫“成功”用绿色，在页面 B 叫“已完成”用蓝色。

### 3. 小红点与未读徽标三档克制与膨胀几何 (Red Dot & Badge Expansion)

1. **红点分级三档克制原则**：
   - **一档（强阻断待处理）**：涉及待办审批、未读告警、关键任务失败，使用**带具体数字的徽标**；
   - **二档（弱提示新内容）**：仅有新功能上线或次级状态更新，使用 **6px–8px 无字纯圆点**；
   - **三档（营销推广/常规通知）**：**严禁悬挂小红点**！杜绝在 B 端系统滥用电子牛皮癣消耗用户注意力。
2. **右上角锚定与向左单向膨胀法则**：
   - **锚点钉死右上角**：徽标几何中心或右上边缘固定在宿主图标/文字容器的右上角（如 `top-0 right-0 -translate-y-1/2 translate-x-1/2`）；
   - **向左单向膨胀**：数字由 1 位递增至多位时（如 `9` 增加到 `99`），徽标宽度必须**向左侧单向延伸伸展**，严禁向右侧或中心外扩覆盖主体图标；
   - **99+ 极值收敛**：数值超过 99 时一律收敛为 `99+`，严禁在徽标内硬塞 3 位以上纯数字破坏胶囊圆弧比例。

## 三、输入与选择控件：二选一否定判据 (Inputs & Selectors)

在表单或筛选场景中，控件选型必须严格遵循认知与操作成本，**严禁无脑全部用下拉框**。

### 1. Radio vs Switch vs Checkbox vs Select 决策表

```
                 选项数量？
                /        \
          2 个选项      3-5 个选项       > 5 个选项
          /      \         |                 |
      互斥状态   二选一动作  单选框(Radio)   下拉选择器(Select)
     (立即生效)  (提交生效)  平铺直观展示    支持模糊搜索过滤
         |          |
    开关(Switch) 单选框(Radio)
```

| 场景 | 正确选型 | 严禁选型 (Avoid) | 理由与否定判据 |
| --- | --- | --- | --- |
| **布尔状态立即生效** | **Switch 开关** | Checkbox 或 Select | 开关代表电路接通，改变后立即触发系统底层状态变更，无需点击“保存”。 |
| **布尔选项提交生效** | **Checkbox 复选框** | Switch | 需要随同整张表单一起点击“提交”才生效的字段，绝不能用 Switch，避免误导用户以为已经即时生效。 |
| **2–4 个互斥选项** | **Radio 单选平铺** | Select 下拉框 | 选项极少时，下拉框需要点开才能看清内容（2次点击+移出移入），单选框平铺能直接一眼扫过并 1 次点击完成。 |
| **5 个以上互斥选项** | **Select 下拉选择器** | Radio 单选 | 选项过多会严重挤占垂直/水平空间，造成界面视觉噪音。 |
| **选项超过 10 个** | **带搜索的 Select** | 普通 Select | 超过 10 项必须支持键盘键入拼音/英文字符模糊检索。 |
| **多项勾选** | **Checkbox 组合** | Multi-Select | 选项少于 6 项时优先平铺复选；选项极多时才使用多选下拉标签栏。 |

## 四、Tag 标签与 Icon 图标规范 (Tags & Icons)

### 1. Tag（标签）与 Badge（徽标）的本质差异
- **Badge（徽标）**：表示**系统客观状态**（如订单已支付、服务异常），是单向告知用户系统事实，用户不可直接删除。
- **Tag（标签）**：表示**主观分类或元数据**（如“VIP客户”、“高净值”、“华东大区”），通常允许用户添加、勾选、删除或带筛选联动。

### 2. 图标选型与视觉减噪 (Icon Rules)
- **严格遵循成熟专业图标库**：统一使用 `Lucide` 或 `Phosphor Icons`，同一产品严禁混用不同风格的图标库（禁止实心粗线条与极细线条并存）。
- **图标尺寸对齐字阶**：
  - 14px 正文配 `16px` 图标；
  - 16px 小标题配 `18px` 图标；
  - 20px 页面大标题配 `20px` 或 `24px` 图标。
- **纯装饰性图标必须去除**：表单里的每个 label 之前不要机械地画一个无意义图标；卡片标题前不需要强加装饰物，保持界面清爽利落。
