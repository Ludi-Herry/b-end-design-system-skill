# 05 页面模板与架构原型 (Page Templates & Archetypes)

B 端系统绝非组件的无序堆砌。“组件库解决有什么零件，页面模板解决如何组装成车”。

---

## 一、列表页模板 (List Page Archetypes)

核心任务：**支持用户高效检索、快速比对与批量流转大量实体。**

```text
PageLayout
├── PageHeader (页面标题 + 核心统计 + 新建主按钮)
├── FilterPanel (查询条件输入 + 下拉筛选 + 重置/查询)
└── DataSection (白底主容器)
    ├── SectionToolbar (数据总数 + 导出/刷新 + 视图切换)
    ├── DataGrid / Table (结构化数据 + 状态Badge + Ghost操作按钮)
    ├── Pagination (分页器)
    └── BulkActionBar (多选浮动操作条，仅选中时滑出)
```

### 列表页五种分支类型与选型判据

| 页面类型 | 核心特征与布局 | 最佳适用场景 |
| --- | --- | --- |
| **查询表格 (Query Table)** | 顶部筛选区 + 标准密集型表格，单列数据包含 6–10 个字段。 | 财务流水、订单中心、设备台账、数据报表。 |
| **标准条目列表 (Standard List)** | 强调对象核心摘要、责任人、进度与阶段，可直接点击展开或跳详情。 | 任务待办、缺陷追踪（Bug List）、审批流水。 |
| **卡片/看板列表 (Card Grid)** | 栅格卡片展示（3-4 列），突出封面、名称、状态指标与快速操作。 | 敏捷看板（Kanban）、设计资产库、商品货架、项目大厅。 |
| **搜索列表 (Search List)** | 以全局大搜索框置顶，内容以高亮富文本或知识片段方式铺开。 | 知识库检索、全局帮助中心、文档资料库。 |
| **成员与权限管理 (Member Admin)** | 左侧部门/组织树（Tree），右侧用户列表与角色分配。 | 企业通讯录、团队管理、RBAC 角色权限矩阵。 |

### 列表页查询与筛选四大骨架 (Data Query & Filter Architecture)

1. **信息查询分层金字塔**：
   - **基础筛选（高频 $\ge 80\%$）**：平铺常驻 3–4 个核心条件，按使用频率从左到右排开，严禁无节制将 8 个以上条件全部平铺占用首屏；
   - **高级筛选（低频 10+ 维度）**：全部收拢进右侧「更多筛选」抽屉（Drawer）或折叠面板，支持条件组嵌套；
   - **自定义视图（View Presets）**：支持将高频多条件组合保存为视图（“我的待办”、“超期未付”、“待我审批”），按“前端本地记忆 $\rightarrow$ 个人私有视图 $\rightarrow$ 团队共享视图”三层演进。
2. **触发时机与体验约束（实时 vs 按钮触发）**：
   - **数据量 $< 1000$ 条且索引覆盖**：采用字段改变即触发的实时刷新；
   - **数据量 $> 10000$ 条或慢查询**：**必须显式提供「查询」与「重置」按钮**。坚决消灭“用户每改一个下拉或日期，页面就立刻转圈锁定”的受刑体验（实测同样改 3 个筛选，逐个查需 12 步转圈，合并点击只需 5 步）。
3. **时间区间选择器四大防呆规约**：
   - **预设胶囊 Pills 外露**：把「今天、近7天、近30天、本月」做成快捷胶囊平铺在时间输入框旁，一键满足 80% 高频查询；
   - **双日历联动选跨度**：手动选择跨度时左右两月并排，**必须设置最大跨度防呆约束**（例如：查秒级日志最多选 24 小时，查流水明细最多选 90 天，未来日期一律置灰禁用）；
   - **同比/环比分析基准线**：右上角提供「对比周期」开关，勾选后图表自动并排渲染上一周期的灰色虚线基准线；
   - **时间格式精确到秒**：统一遵循 `YYYY-MM-DD HH:mm:ss`，禁止不同模块出现混用格式。
4. **树形关系标签多选防炸框**：
   - 部门、组织或分类树多选时，**必须按父级自动收拢**：例如勾选全研发部，标签栏只显示 1 个「研发部全部」，严禁铺出 50 个人名导致输入框瞬间撑爆两屏；
   - 超出预设宽度时自动收敛为 `+N` 徽标，Hover 或点击展开悬浮浮层预览。

## 二、表单页模板 (Form Page Archetypes)

核心任务：**保障信息准确录入，降低填写阻力，杜绝意外丢失。**

### 1. 表单复杂度的四大梯度

```
① 基础单列纵向布局 (Basic Form)
   - 字段 < 6 个，单列自上而下，垂直阅读动线最顺畅。严禁随意并列多列。

② 弱分组表单 (Inline Row Form)
   - 包含逻辑强相关的短字段（如“省/市/区”、“姓/名”、“单价/数量”），仅在此处允许合并同行。

③ 区域分组表单 (Sectioned Form)
   - 字段 8–15 个，用带标题的白底卡片或灰色小底块进行语义分区（如“基础资料”、“结算账号”）。

④ 卡片/分步表单 (Stepper / Wizard Form)
   - 流程有明确的先后因果依赖（如“选择方案 → 填写主体 → 绑定支付 → 确认发布”），以步骤条引导。
```

### 2. 表单核心交互铁律
- **对齐规范**：中文 B 端系统首选 **Top-aligned（标签置于输入框上方）**，录入效率最高且对不同长度的标签适配最好。
- **校验反馈即时性**：失焦（OnBlur）触发单字段格式校验，严禁等用户填完整张表点提交时才突然爆出 10 个红框。
- **离开防丢失提示**：检测到表单已发生修改（`isDirty`）时，用户若点击侧边栏或关闭标签页，必须弹出浏览器级离开确认。

## 三、详情页模板 (Detail Page Archetypes)

核心任务：**完整呈现对象全貌，支持状态推进与审计追溯。**

```text
PageLayout
├── DetailHeader (返回链路 + 对象名称 + 状态Badge + 核心操作栏)
├── MetricsRow? (关键快照指标，如总金额、总耗时)
├── DescriptionGrid (稳定静态基础属性栅格)
└── TabsContainer (复杂维度的辅助页签)
    ├── Tab 1: 业务主体明细 (关联子表格)
    ├── Tab 2: 审计流转与操作日志 (Timeline 时间线)
    └── Tab 3: 关联附件与相关配置
```

### 详情页类型分支

| 详情类型 | 适用场景 | 布局重点 |
| --- | --- | --- |
| **基础单据详情** | 简单订单、用户信息、设备单页。 | 采用 DescriptionGrid 配合 1-2 个信息卡片，平铺展开。 |
| **高级协同详情** | 复杂的 CRM 商机、客户画像、复杂项目单页。 | 顶层基础属性 + 底部标签页（Tabs）切分各个独立业务视角。 |
| **审批流单据详情** | 报销单、请假审批、采购核决。 | 页面上方突出“审批阶段时间线（Timeline）”，底部常驻“同意/驳回”操作栏。 |

### 4. 国际化出海与响应式操作栏百分比弹性切割
在出海多语言（i18n）环境下，底部常驻操作栏与浮动条严禁将按钮宽度写死：
- 桌面宽屏下主按钮与辅助按钮通过 `min-w-[80px] w-auto px-4` 自适应外文扩展；
- 在响应式窄屏或嵌入移动设备时，执行大厂**百分比切割法**（左侧辅助区按五档定宽 72%/43%/28%/13%/0%，右侧主操作容器 `flex-1` 弹性填满剩余空间），杜绝欧系多语言长词撑爆折行。

## 四、数据看板与工作台模板 (Dashboard & Workbench)

核心任务：**呈现业务健康度，辅助决策，提供一键行动入口。**

```text
PageLayout
├── WorkbenchHeader (问候语 + 今日核心待办统计)
├── KPI Metric Cards (3-4 个核心量化指标卡片，包含当前值与同环比趋势)
├── Charts Section (主图表区：趋势折线图、结构饼图或漏斗图)
└── QuickAction & RecentActivity Grid (双栏：左侧快捷入口，右侧最新系统动态列表)
```

### 看板设计硬门禁
- **指标卡控制在 3–4 个**：统一时间口径（如“本月截止至今”），禁止一个屏幕塞进 12 个指标让人眼花缭乱。
- **图表严禁当成纯装饰**：图表必须能回答具体的业务问题（如“销售业绩是否在下滑”）；图表库首选轻量 DOM/CSS 或稳定封装，严禁为了好看引入体积超 1MB 的冗余大图表库。
- **复杂图表跨端响应式断点（EP12）**：
  - **桌面超宽屏 ($\ge 1440$px)**：3–4 栏并排，左侧核心趋势折线 + 右侧结构占比饼图；
  - **中屏/平板 ($768$–$1280$px)**：折叠为上下堆叠双栏，图表与关联明细表格并排或一键抽屉滑出；
  - **移动端窄屏 ($< 768$px)**：图表自动简化维度，指标卡垂直单列排列，下方复杂数据表格自动转化为结构化卡片流（Card List），严禁直接横向硬塞多列表格。
- **极端数值截断与对数坐标防变形**：当数值跨度超 100 倍时，启用局部放大（Data Zoom）或平滑对数坐标，防止矮数值贴地无法分辨。

## 五、设置页模板 (Settings Page Archetypes)

核心任务：**配置应用底层规则、个性化偏好与第三方集成。**

### 1. 结构与导航
- 采用 **左侧设置分类导航 (SubNav) + 右侧设置内容卡片** 的经典双栏架构。

### 2. 即时生效 vs 提交保存判据
- **自服务个人偏好（如深浅模式、通知接收选项）**：采用 Switch 或 Radio，**更改后立即自动保存**，并伴随微 Toast“设置已更新”。
- **系统核心规则配置（如结算手续费率、发票抬头、集成 API Key）**：采用完整表单，必须显式点击页面底部的“保存更改”主按钮，以防误触引发全站业务规则震荡。
